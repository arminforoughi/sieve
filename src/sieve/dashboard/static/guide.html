Methods and caveats

What the numbers are, how far to trust them, and how to reproduce them. The agent workflow itself is on How it works.

The question

Which CoRE MOF 2019 structures adsorb the most CO₂ at 298 K and 1 bar, in one fixed molecular model, on 4 CPU-hours? Of 12,020 structures, 8,803 pass the pore filter (PLD ≥ 3.3 Å). Simulating all of them even at the cheapest useful fidelity would take about 220 CPU-hours, so most are never simulated. SIEVE ranks structures within its model; it does not predict laboratory uptake.

Tiers and error bars

  • T0 descriptors only (pore sizes, void fraction, density, metals). Seconds; no uptake.
  • T1 short GCMC, 100 + 500 cycles. Not converged (nominal ±18%): it ranks, it never names a winner.
  • T2 confirmed GCMC, 400 + 2000 cycles (nominal ±8.6%). Only a tier-2 structure may be recommended.
  • T3 capture check, runs with the capture objective only, on tier-2-confirmed finalists: a 15:85 CO₂/N₂ mixture at 1 bar and pure CO₂ at 0.01 bar, 200 + 500 cycles each. It reports selectivity S, working capacity ΔN and APS (below).

Uptake is absolute loading in mol/kg (= mmol/g). The ± is one standard deviation from RASPA's block averages: simulation noise, not model error. Overlapping tier-1 intervals are not distinguishable.

Two objectives

  • uptake (default): rank by CO₂ uptake at 298 K and 1 bar; the winner is the best tier-2-confirmed structure.
  • capture (--objective capture): the same screen finds candidates, then the winner is the capture-checked structure with the highest APS = S(CO₂/N₂) × ΔN (mol/kg), the adsorbent performance score of Chung et al., Sci. Adv. 2016: S from the 15:85 mixture, ΔN = mixture CO₂ loading − pure-CO₂ loading at 0.01 bar (vacuum-swing desorption). Phases: explore T1 → confirm T2 → capture check T3. Baselines end with the same capture check of their own top 3, so arms stay comparable.
  • Runs with different objectives answer different questions; Compare shows each run's objective.

MOFs and zeolites

--pool mixed adds the IZA zeolite frameworks zeolite to the CoRE MOFs. Their pore descriptors (PLD, LCD, void fraction, surface area) are computed by SIEVE on a distance grid with CoRE's definitions and radii; on 20 CoRE MOFs they match CoRE's Zeo++ values to 0.04 Å (LCD), 0.09 Å (PLD, calibrated out) and 0.005 (void fraction); surface area runs low. The zeolites are pure silica with no cations, so this model treats them fairly only geometrically: real cation-exchanged zeolites (13X, 5A) bind CO₂ electrostatically.

Model limits

  • No framework charges. UFF Lennard-Jones + TraPPE CO₂, Lorentz–Berthelot, 12.8 Å shifted cutoff. Open metal sites and polar pockets are under-rated: Mg-MOF-74 comes out near 1.7 mol/kg here against about 8 measured.
  • Rigid frameworks, no water. CO₂/N₂ selectivity is computed only for leads (15:85 mixture); humid performance is not addressed.
  • Disordered crystal files disordered. Some cleaned CIFs keep one site twice, which can inflate binding. A disorder check flags them; before a flagged structure can be recommended, the critic has it re-measured at tier 2 on a resolved copy (one atom of each overlapping pair removed). The recommendation uses the resolved value; a drop of more than 15% is a disorder artefact and vetoes the original.

How SIEVE is judged

  • Three fixed-policy baselines (random, descriptor-ranked, uniform tier-2) get the same 4 CPU-hours.
  • A referee re-measures every arm's top 10 at tier 2 with new seeds; no AI is involved.
  • An arena of 300 structures, scored on the 292 with a converged tier-2 answer, replays each arm over many seeds.
  • Losses are reported. When a baseline beats SIEVE, Compare says so first, with live numbers.

Reproduce

uv run python -m sieve sieve --budget-h 4             # the agent team
uv run python -m sieve sieve --arm sieve-v5 --objective capture --pool mixed   # flue-gas capture, MOFs + zeolites
uv run python -m sieve baseline random --budget-h 4   # also: descriptor, uniform; --objective capture --pool mixed
uv run python -m sieve resume <run_id>                # continue after a crash or kill -9
uv run python -m sieve status [<run_id>]
uv run python -m sieve dashboard --port 8770          # this dashboard; --demo-replay <run_id> replays a run

Every evaluation, task and event is recorded in data/runs.db, so any run can be replayed and audited. Science-page results are cached in data/science/.
