What SIEVE is, and how to read it

A short guide for a materials scientist who wants to know what these numbers are, how far to trust them, and how to reproduce them.

The question it answers

Which metal–organic frameworks, out of 12,020 CoRE MOF structures, adsorb the most CO₂ at 298 K and 1 bar, in one fixed molecular model, on a budget of 4 CPU-hours? An exhaustive screen at the cheapest useful fidelity would need roughly 220 CPU-hours, so most structures are never simulated. LLM agents (orchestrator, scout, allocator, critic, analyst) decide which structures to simulate and at which fidelity; three fixed-policy baselines (random, descriptor-ranked, uniform tier-2) get the same budget so the agents can be judged.

SIEVE ranks structures within its model. It does not predict laboratory uptake.

Reading tiers and error bars

  • T0 descriptors only (pore-limiting and largest cavity diameter, void fraction, density, metals). Costs seconds; no uptake.
  • T1 short GCMC (100 + 500 cycles at 1 bar). Not converged: nominal ±18%. Good for deciding what to look at next, never for naming a winner.
  • T2 confirmed GCMC (400 + 2000 cycles), nominal ±8.6%. A run may only recommend a structure that reached tier 2.

Uptake is absolute loading in mol/kg (= mmol/g). The ± is one standard deviation from RASPA's block averages: it is the statistical noise of the simulation, not the error of the model. Two structures whose intervals overlap at tier 1 are not distinguishable.

Limitations to keep in mind

  • No framework charges. The force field (UFF Lennard-Jones + TraPPE CO₂, Lorentz–Berthelot, 12.8 Å cutoff, shifted) has no electrostatics with the framework, so open metal sites and other polar binding sites are under-rated. Mg-MOF-74 comes out near 1.7 mol/kg here, against roughly 8 in experiment.
  • Rigid frameworks, pure CO₂, no water, no N₂ competition: selectivity and humid performance are not addressed.
  • The CoRE structures are taken as given (solvent removed, as curated); disorder and missing hydrogens are not repaired.
  • Budgeted search can miss the best structure. The arena on the Compare page measures how often each arm does.

Reproduce

From the repository root, with the project's virtual environment:

python -m sieve sieve --budget-h 4             # the agent team
python -m sieve baseline random --budget-h 4    # also: descriptor, uniform
python -m sieve resume <run_id>               # continue a crashed run
python -m sieve status [<run_id>]
python -m sieve dashboard --port 8770           # this dashboard

Everything a run does is recorded in data/runs.db (evaluations, tasks, events), so a run can be replayed (dashboard --demo-replay <run_id>) and audited. Science-page results are cached in data/science/.

Honest status

On the full pool so far, a baseline (uniform tier-2) holds the best confirmed structure (ZADREE, about 9.6 mol/kg), above SIEVE's best confirmed one. Across arena seeds SIEVE does not yet beat random search on median best-found uptake. See Compare for the current numbers; they update as runs finish.
